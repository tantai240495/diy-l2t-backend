# Workflow: Daily Brief

Hermes summarizes:

- email that requires attention or a response;
- Backlog projects or documents that require action;
- Offwork requests or rewards that require attention;
- new customer or internal requests in Mattermost when thread/search tools exist;
- GitHub issues and pull requests when GitHub tools exist;
- the user's calendar for the day;
- coding jobs waiting for approval.

Hermes must not automatically send email, modify code, merge, deploy, post to
Mattermost, update Backlog, redeem rewards, or cancel Offwork requests.

## Output

1. Immediate actions.
2. Coding work.
3. Messages or email that require a response.
4. Items that can be deferred or ignored.
5. Pending approvals.
